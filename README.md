<b>NAME</b>
       misha - builds and fixes things

<b>SYNOPSIS</b>
       misha [--build | --fix] &lt;system&gt;

<b>DESCRIPTION</b>
       Backend and systems work: the services under products people use
       every day — live video, presence, messaging, the social graph — and
       the storage, caching and infrastructure beneath them. Lately, the
       tools that let AI agents see and drive real software.

       Linux since 1999. Debian developer, emeritus.

<b>PROJECTS</b>
       <a href="https://github.com/uniqush/uniqush-push">uniqush-push</a>
              Push notification server: APNs, FCM, Web Push, UnifiedPush.
              Maintainer.

       <a href="https://github.com/mishan/intraslot">intraslot</a>
              Set intersection on Redis Cluster without CROSSSLOT. Found a
              slot-hashing bug on the way; fixed in ioredis and node-redis.

       <a href="https://github.com/mishan/hxd-ng">hxd-ng</a>, <a href="https://github.com/mishan/hx-ng">hx-ng</a>

       <a href="https://github.com/mishan/shotbox">shotbox</a>

              tests for scripts and CI too.

              <a href="https://github.com/mishan/mullion-gtk">mullion-gtk</a>, one tiling layout for web pages and GTK 4.
